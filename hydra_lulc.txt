          <li>Cloud/cirrus masking of Sentinel-2 using the QA60 band; reflectance scaled by 0.0001.</li>
          <li>Median composite (Jan–Apr 2025) clipped to the Hyderabad boundary, processed at 10 m.</li>
          <li>Predictor bands: B2, B3, B4, B8, B11, B12, plus derived indices NDVI, NDBI and MNDWI.</li>
          <li>Training samples digitised for five classes: water, built-up, vegetation, cropland, bare land.</li>
          <li>Classifier: Random Forest (smileRandomForest), 200 trees, seed 42.</li>
          <li>Post-classification smoothing with a focal-mode filter to reduce salt-and-pepper noise.</li>

<script>
  // Accordion: clicking a header opens its body and closes the others.
  var items = document.querySelectorAll('#accordion .acc-item');

  function setHeight(item, open){
    var body = item.querySelector('.acc-body');
    if (open){
      item.classList.add('open');
      body.style.maxHeight = body.scrollHeight + 'px';
    } else {
      item.classList.remove('open');
      body.style.maxHeight = 0;
    }
  }

  items.forEach(function(item){
    var header = item.querySelector('[data-toggle]');
    header.addEventListener('click', function(){
      var isOpen = item.classList.contains('open');
      items.forEach(function(other){ setHeight(other, false); });
      if (!isOpen) setHeight(item, true);
    });
  });

  window.addEventListener('load', function(){
    setHeight(items[0], true);
  });

  window.addEventListener('resize', function(){
    items.forEach(function(item){
      if (item.classList.contains('open')) setHeight(item, true);
    });
  });
</script>
